# KURULUM NOTLARI

# 1) CPU-only PyTorch (GPU yoksa, ~2GB küçük):
#    pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
#
# 2) GPU destekli PyTorch (NVIDIA, CUDA 12.1):
#    pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu121
#
# 3) Ollama ayrı kurulur (pip ile değil):
#    https://ollama.com/download
#    Sonra: ollama pull llama3.2
#           ollama pull llava          (görüntü için)
#           ollama pull mistral        (alternatif LLM)
#
# 4) Gemini API key almak için (ücretsiz):
#    https://ai.google.dev/gemini-api
#    .env dosyasına: GOOGLE_API_KEY=AIza...
#
# 5) pyaudio kurulumu Linux/Mac için ek paket gerektirir:
#    Ubuntu: sudo apt-get install portaudio19-dev
#    Mac:    brew install portaudio
